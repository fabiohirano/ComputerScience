Declaring Variables & Constants in Pseudocode

A self-paced guide to storing information in your programs — what a variable is, how to declare one with the correct data type, and when to use a constant instead.

1 · Foundations

What Is a Variable?

A variable is a named location in a computer's memory where a program can store a single piece of information while it runs.

Think of a variable as a labelled box. The label on the outside — the variable's name — tells you, and the computer, what the box is for. Unlike the label, the contents of the box are not fixed: a program can put a value in, read it, and later replace it with a different value, all while the program is running. That is the entire point of a variable — it is a container whose contents are allowed to vary.

The box keeps the label Age, but the value inside can be replaced the next time the program runs a line that changes it — for example, on a birthday.

Every variable has three things associated with it: a name, so your code can refer to it; a data type, so the computer knows what kind of value it is allowed to hold; and a value, which is whatever is currently stored inside. Before you can use a variable in pseudocode, you must first declare it — the next card shows you exactly how.

1 · Foundations

Declaring a Variable

Declaring a variable is how you tell the computer "create this box, give it this name, and only ever let it hold this kind of value."

In pseudocode, a declaration always follows the same pattern:

DECLARE <variable name> : <data type>
DECLARE
the keyword that tells the reader (and, in a real program, the computer) that a new variable is being created here for the first time.
<variable name>
the label you choose for the box — for example Age or Name. Pick a name that describes what the variable stores.
<data type>
tells the computer exactly what kind of value the variable is allowed to hold, such as a whole number or a piece of text. You will meet all five data types on the next card.

Notice that a declaration on its own does not put anything inside the box yet — it only creates the box and labels it. Giving the box an actual value is a separate step called assignment, which you will meet in a couple of cards' time.

1 · Foundations

What Are Data Types?

A data type defines the kind of information that a variable is allowed to store.

Computers treat numbers, text and true/false values very differently in memory, so every variable must be given a data type when it is declared. This also helps you: naming the type up front stops you from accidentally trying to store a name inside a variable meant for a number. Pseudocode uses five common data types:

INTEGER
Whole numbers, with no decimal part. Can be positive, negative or zero.
10-50
REAL
Numbers with decimals — used whenever precision beyond a whole number matters.
3.14-7.5
STRING
A sequence of characters — any piece of text, held inside quotation marks.
"Hello""John123"
CHAR
A single character only — one letter, digit or symbol.
'A''7''$'
BOOLEAN
A logical value — there are only ever two possibilities.
TRUEFALSE

Look carefully at the difference between STRING and CHAR: a CHAR can only ever hold one single character, while a STRING can hold many characters strung together — even an entire sentence. If you are ever unsure which to use, ask yourself: "could this value ever need more than one character?" If yes, use STRING.

2 · Putting Values In

Assigning a Value

Declaring a variable creates an empty, labelled box. Assignment is the step that actually puts a value inside it.

To assign a value, write the variable's name, followed by the assignment symbol ←, followed by the value you want stored. You can read the arrow as "is set to" or "becomes":

<variable name> ← <value>

Putting the two steps together, a complete example looks like this:

DECLARE Age : INTEGER Age ← 15

The first line creates a box named Age that is only allowed to hold whole numbers. The second line puts the value 15 inside it. Because Age is a variable and not a constant, a later line could reassign it — for example Age ← Age + 1 would replace the value with one more than whatever it currently holds. This is exactly what makes a variable different from a constant, which you will meet later in this guide.

2 · Putting Values In

Displaying a Result with OUTPUT

Storing a value is only useful if your program can eventually show it to the user. That is the job of the OUTPUT command.

OUTPUT displays whatever follows it on the screen. You can output a piece of literal text in quotation marks, the value stored in a variable, or — very commonly — both together, separated by a comma:

OUTPUT "The age is ", Age

If Age currently holds 15, this line displays exactly: The age is 15. The quoted text is printed exactly as written, and the comma tells the computer "now print whatever this variable currently contains" straight after it. You will use this pattern constantly in the worked examples on the next few cards.

3 · Worked Examples

Worked Example — an INTEGER Variable

Task: Write pseudocode to declare an integer variable and assign it the value 15. Output the stored value.
DECLARE Age: INTEGER Age ← 15 OUTPUT "The age is ", Age

Line by line

Line 1Declares a new variable called Age and restricts it to whole numbers only, using the INTEGER data type. Line 2Assigns the value 15 to Age, using the assignment symbol. Line 3Outputs the literal text "The age is " immediately followed by whatever value Age currently holds — displaying The age is 15.

3 · Worked Examples

Worked Example — a REAL Variable

Task: Write pseudocode to declare a real variable and assign it the value 4.5. Output the stored value.
DECLARE Temperature: REAL Temperature ← 4.5 OUTPUT "The temperature is ", Temperature

The pattern is identical to the INTEGER example — only the data type changes. REAL is chosen here instead of INTEGER because a temperature reading needs a decimal point to be accurate; declaring it as INTEGER would not allow the .5 to be stored correctly. Whenever a quantity might need decimal precision — money, measurements, averages — reach for REAL rather than INTEGER.

3 · Worked Examples

Worked Example — a STRING Variable

Task: Write pseudocode to declare a string variable and assign it the value "John". Output the stored value.
DECLARE Name: STRING Name ← "John" OUTPUT "The name is ", Name

Because text is being stored, the data type is STRING and the value being assigned is wrapped in quotation marks — "John" rather than John. The quotation marks are part of the pseudocode syntax, not part of the stored text itself: they simply mark where the string begins and ends, in exactly the same way that quotation marks mark the literal text inside an OUTPUT statement.

4 · Constants

What Is a Constant?

A constant is a special kind of variable. Once you give it a value, that value never changes for as long as the program is running.

Think back to the labelled box from earlier: a constant is a box that gets sealed shut the moment a value is placed inside it. You can still read what's in the box any time you like, but no line of the program is ever allowed to swap it for something else. Some real-world values are constant by their very nature — they would not make sense as ordinary, changeable variables:

Hours in a day

Always 24. No calculation in your program should ever cause this to become a different number.

The value of Pi (π)

Always approximately 3.14159. It is a mathematical fact, not something a program calculates or changes.

Values like these are "perfect for constants" precisely because there is never a legitimate reason for them to change while the program runs.

4 · Constants

Why Use Constants?

It would be technically possible to use an ordinary variable everywhere instead of a constant — so why bother with a separate keyword at all?

Easy to update

If a fixed value needs to change in the future, you only have to update it in the one place where the constant is declared, instead of hunting through the whole program.

Avoid mistakes

Because a constant's value is locked, you can't accidentally overwrite it somewhere else in the code — which keeps your program's results accurate and predictable.

Improves readability

A well-chosen, descriptive constant name makes your pseudocode easier for anyone — including you, later on — to read and understand at a glance.

In short: use a constant whenever a value is fixed and meaningful, and reserve ordinary variables for anything that is genuinely expected to change while the program runs.

4 · Constants

How to Write a Constant

A constant is declared and given its value in a single line — unlike a variable, there is no separate declare-then-assign step.

CONSTANT <Identifier> ← <Value>
CONSTANT
the keyword that tells the reader this value is fixed and will never change — this is what makes a constant different from DECLARE.
<Identifier>
the name of the constant. By convention it is written in Pascal Case — each word capitalised with no spaces, such as HoursInDay.
←
the same assignment symbol used for variables — it means "is set to".
<Value>
the fixed value being stored, written immediately after the arrow.

Examples

Hours in a day
CONSTANT HoursInDay ← 24
Maximum game score
CONSTANT MaxScore ← 100
Price of a bus ticket
CONSTANT TicketPrice ← 5.50

Variables vs. Constants — a Quick Comparison

Now that you have met both, it is worth holding them side by side so the difference is completely clear.

A useful rule of thumb: if you catch yourself asking "will this value ever need to be updated while the program is running?" — answer yes, and it belongs in a variable; answer no, and it belongs in a constant.

Key Vocabulary Recap

Before you move on to the worksheet, check that you can explain each of these terms in your own words.

VariableA named location in memory that stores a value which is allowed to change while the program runs.
ConstantA named value that is fixed once declared and can never change while the program runs.
Data typeDefines what kind of value a variable may store — INTEGER, REAL, STRING, CHAR or BOOLEAN.
DeclareTo create a new variable, giving it a name and a data type, using the DECLARE keyword.
