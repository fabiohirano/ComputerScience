Quick reference — syntax reminder
DECLARE <name> : <data type>  — creates a variable
<name> ← <value>  — assigns a value to it
CONSTANT <Identifier> ← <Value>  — creates a fixed value, in one line
INTEGER — 10, -5, 0 REAL — 3.14, -7.5 STRING — "Hello" CHAR — 'A', '$' BOOLEAN — TRUE / FALSE

Part B — Declaring Variables

1.Declare a variable to store a person's height as a decimal number. What data type should you use? Write the pseudocode.
try it before you check!
Model answerDECLARE Height : REAL
2.Write pseudocode to:
  1. Declare a variable to store a student's grade as a single letter.
  2. Assign it the value 'B'.
try it before you check!
Model answerDECLARE Grade : CHAR Grade ← 'B'
3.Create a pseudocode program to:
  1. Store your age.
  2. Calculate your age in 10 years.
  3. Output the result.
Hint: to calculate a new value from an existing one, assign a variable using an expression, e.g. NewAge ← Age + 10
try it before you check!
Model answer — your age will differ, that's fineDECLARE Age : INTEGER Age ← 15 NewAge ← Age + 10 OUTPUT "In 10 years I will be ", NewAge
4.Write pseudocode to:
  1. Declare a variable to store a string containing a person's name.
  2. Display the message: "Welcome, <name>!"
try it before you check!
Model answerDECLARE Name : STRING Name ← "Fabio" OUTPUT "Welcome, ", Name, "!"
5.Declare a variable to check if a car is available (TRUE or FALSE). Assign it the value TRUE. What data type should you use? Write the pseudocode.
try it before you check!
Model answerDECLARE CarAvailable : BOOLEAN CarAvailable ← TRUE

Part C — Working with Constants

6.A school lesson period always lasts exactly 50 minutes, and this should never change in your program. Declare this as a constant.
try it before you check!
Model answerCONSTANT LessonLength ← 50
7.Write pseudocode for a constant that stores the value of Pi as 3.14159.
try it before you check!
Model answerCONSTANT Pi ← 3.14159
8.A programmer stores a cinema ticket price using CONSTANT TicketPrice ← 5.50. In one or two sentences, explain why this should be a constant rather than an ordinary variable.
try it before you check!
Model answerBecause the price is fixed and should never accidentally change while the program is running, it needs to be locked as a constant rather than left as an editable variable — this avoids mistakes and makes the code easier to read.

Part D — Challenge

9.A school canteen sells a set-price lunch. The price never changes and is always $12.50. Write a short pseudocode program that:
  1. declares the lunch price as a constant;
  2. declares a variable to store how many lunches a pupil buys today, and assigns it the value 2;
  3. outputs a message that includes the number of lunches bought.
try it before you check!
Model answerCONSTANT LunchPrice ← 12.50 DECLARE LunchesBought : INTEGER LunchesBought ← 2 OUTPUT "Lunches bought: ", LunchesBought
